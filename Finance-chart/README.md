# 금융사 연표 차트

1600년부터 오늘까지 금리·금·환율·비트코인 등을 한 화면에서 겹쳐 보고, 차트 위에 메모를 남기는 웹 프로그램입니다.
책으로 금융·자본주의 역사를 공부할 때 "이 사건이 몇 년이었지?"를 시기별 흐름으로 확인하려고 만들었습니다.

## 구성 (파일 설명)

| 파일 | 역할 |
|---|---|
| `index.html`, `app.js`, `style.css` | 차트 화면 |
| `config.js` | 메모 저장소(Supabase) 주소와 공개용 키 (공개되어도 안전한 키) |
| `events.json` | 역사 사건 표시 목록 (⚠ 날짜는 직접 검증 필요) |
| `collector/collect.py` | 데이터를 내려받아 `data/` 폴더에 저장하는 프로그램 |
| `.github/workflows/update.yml` | 매일 한국시간 06:30 에 데이터를 갱신하고 사이트를 배포 |
| `data/` | 수집된 데이터 (처음엔 비어 있고, 아래 5번 실행 후 채워짐) |

## 처음 한 번만 하는 설정

> 이 프로그램은 **GitHub 이 대신 데이터를 내려받는 방식**입니다. 제 작업 환경에서는 FRED·한국은행·바이낸스 사이트에 접속할 수 없어, 데이터는 GitHub 이 처음 실행될 때 채워집니다.

### 1. 무료 키 발급 (직접 하셔야 합니다)
- **한국은행 ECOS 인증키** (필수: 한은 기준금리에 필요): https://ecos.bok.or.kr/api/ 에서 "인증키 신청"
- **FRED API 키** (선택: 없어도 동작): https://fredaccount.stlouisfed.org/apikeys

### 2. GitHub 저장소 만들기
1. https://github.com 에 가입/로그인
2. 오른쪽 위 `+` → **New repository** → 이름 `finance-chart`, 공개 범위 **Public** 선택 → Create
   (무료 계정은 Public 저장소여야 GitHub Pages 를 쓸 수 있습니다. 공개되는 것은 코드와 공개 경제 통계뿐이고, 메모는 공개되지 않습니다.)
3. 저장소 화면의 **uploading an existing file** 을 눌러, 이 Finance-chart 폴더 **안의 모든 파일과 폴더**를 끌어다 놓고 Commit
   - 맥에서 `.github` 폴더는 숨김 폴더라 안 보일 수 있습니다. Finder 에서 `Command + Shift + .` 을 누르면 보입니다.
   - 끝내 올리기 어려우면: 저장소에서 **Add file → Create new file** 을 누르고 파일 이름 칸에 `.github/workflows/update.yml` 을 입력한 뒤, `setup/update.yml` 의 내용을 붙여넣으세요.

### 3. 키를 GitHub 에 등록
저장소 → **Settings → Secrets and variables → Actions → New repository secret**
- 이름 `ECOS_API_KEY` / 값: 한국은행에서 받은 키
- 이름 `FRED_API_KEY` / 값: FRED 키 (선택)

### 4. GitHub Pages 켜기
저장소 → **Settings → Pages → Build and deployment → Source: GitHub Actions** 로 선택

### 5. 첫 실행
저장소 → **Actions** 탭 → "데이터 갱신 및 배포" → **Run workflow**.
3~5분 뒤 초록색 체크가 뜨면 **Settings → Pages** 에 사이트 주소(`https://아이디.github.io/finance-chart/`)가 나옵니다. 이 주소를 맥북에서 열면 됩니다.
- 실행 요약(Summary)에 지표별 성공/실패가 나옵니다. 실패한 지표가 있으면 그 내용을 저에게 알려주세요.
- 이후에는 매일 자동으로 갱신됩니다.

### 6. 로그인(메모 저장) 설정 — Supabase
프로젝트 이름 `finance-chart` (이미 만들어 두었습니다). https://supabase.com/dashboard 에서:
1. **Authentication → Sign In / Providers → Email**: 처음엔 "Confirm email"(이메일 확인)을 **끄면** 가입 즉시 쓸 수 있습니다. 켜 두면 확인 메일을 눌러야 로그인됩니다.
2. **Authentication → URL Configuration**: Site URL 에 5번에서 나온 사이트 주소를 넣고 저장
- 사용자마다 자기 메모만 보이도록 보호되어 있습니다 (행 수준 보안).

## 사용법
- **지표 켜기/끄기**: 왼쪽 목록 클릭. 여러 개를 겹쳐 볼 수 있습니다.
- **확대/축소**: 마우스 휠 또는 위쪽 `+` `−`. 드래그로 좌우 이동. 기간 버튼(최대, 100년 … 1개월, 맞춤).
- **단위가 다른 지표**(금리 % 와 달러 가격)는 좌/우 축에 나눠 그립니다. 단위가 3종류 이상이거나 "시작=100 비교"를 켜면 한 축에 맞춰 비교합니다. "로그 눈금"은 큰 폭으로 오른 가격을 보기 좋게 합니다.
- **환율**: 왼쪽 "환율"에서 기준통화와 표시통화를 골라 "추가". 예: 1달러당 유로, 1엔당 원.
- **메모**: 차트 클릭 → "메모 추가하기". 저장 위치를 *연표(항상 보임)* 또는 *특정 지표와 함께(그 지표를 숨기면 메모도 숨음)* 로 고르고, 표시 방식을 *작은 점* 또는 *글씨로 항상 표시* 로 고릅니다. 메모(점/글씨)를 클릭하면 수정·삭제할 수 있습니다. 아래 "메모 표시"에서 전체를 한꺼번에 점/글씨로 바꿀 수도 있습니다.
- **역사 사건**: 아래 줄의 보라색 마름모. 마우스를 올리거나 클릭하면 설명이 나옵니다.

## 데이터 출처와 ⚠ 검증이 필요한 부분

| 지표 | 출처 | 비고 |
|---|---|---|
| 미국 연방기금금리 | FRED `DFF` (일별 1954~) | |
| 한국은행 기준금리 | 한국은행 ECOS `722Y001`/`0101000` | ⚠ 통계표·항목 코드는 문서/예제로 확인했으나 첫 실행에서 값 확인 필요. 1999.5 이전 없음 |
| 영국은행 기준금리 | 영국은행 장기통계(연 단위) + IADB 일별 | ⚠ 엑셀 열을 자동으로 찾는 방식이라 첫 실행 뒤 원본과 대조 필요 |
| 네덜란드 정부채 금리 | Schmelzing(2020, 영국은행 Working Paper 845) 부속 데이터 | ⚠ 학술 재구성 추정치, 열 자동 탐색 |
| 금 (USD, 월별) | datasets/gold-prices (1833~1959 Timothy Green, 1960~ 세계은행) | 일별 아님 (LBMA 일별은 라이선스가 필요해 제외) |
| 금 (GBP, 장기) | 영국은행 장기통계 | ⚠ 열 자동 탐색, 단위·시작연도 대조 필요 |
| 환율 | FRED H.10 (원 1981~, 엔 1971~, 위안 1981~, 유로 1999~, 파운드 1971~) | 달러 기준 값에서 교차환율 계산 |
| 비트코인·이더리움 | 바이낸스 일봉 종가(USDT) 2017.8~, 업비트 원화 일봉 | USDT 기준. 2017년 이전 비트코인은 없음 |
| 미국 10년물, CPI, 유가, ECB·일본 금리 | FRED | ⚠ ECB·일본 금리 시리즈 코드 확인 필요 |

- **1600년부터 모든 지표가 있는 것은 아닙니다.** 지표마다 자료가 시작되는 해가 다르고, 옛 자료는 연 단위·추정치입니다. 선이 중간에서 시작하는 것은 정상입니다.
- 각 지표 옆 `ⓘ` 에 마우스를 올리면 출처와 실제로 사용한 자료가 나옵니다.
- `events.json` 의 사건 날짜는 제 기억을 바탕으로 적은 것이라 **반드시 책이나 신뢰할 만한 자료로 확인**하세요.
- 안내 문구를 그대로 믿기보다, 첫 실행 후 몇 개 값(예: 특정 날짜의 연방기금금리)을 원본 사이트와 비교해 보시길 권합니다.

## 지표를 더 넣고 싶을 때
`collector/collect.py` 아래쪽 `SERIES` 목록에 FRED 시리즈를 한 줄 추가하면 됩니다. 예:
```python
S("us_unrate", "미국 실업률", "macro", "%", lambda: fred("UNRATE"), freq="monthly", source="FRED UNRATE", url=FRED_URL + "UNRATE", order=2),
```
(원하시는 지표를 말씀해 주시면 추가해 드립니다.)

## 내 컴퓨터에서 미리 보기 (선택)
이 폴더에서 터미널로 `python3 -m http.server 8000` 실행 후 브라우저에서 `http://localhost:8000/index.html?local` 을 열면, 로그인 없이 이 브라우저에만 저장되는 "로컬 모드"로 볼 수 있습니다. (데이터 폴더가 채워져 있어야 합니다.)
